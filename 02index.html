가고 싶은 도시를 선택

만들 때 사용한다. margin은 두 블록 사이의 간격을 벌리고 싶거나, 카드 요소끼리 겹치지 않게 외부 간격을 padding은 버트 내부의 텍스트와 버튼 테두리 사이 간격을 늘려 클릭 영역을 키울 때, 또 카드 안의 텍스트가 테두리에 붙지 않게 할 때 사용한다. 1. 라디오 버튼들은 동일한 name=“fruit” 을 갖고 있어 한 그룹으로 묶인다. 2. CSS 선택자 input[name=“fruit”]:checked 는 그 그룹 중 체크된(선택된) 요소만을 지정한다. 3. document.querySelector(...)는 주어진 선택자에 처음 매칭되는 한 개의 요소를 반환한다. ( :checked 때문에 해당 그룹에서 반환되는 건 곧 선택된 하나뿐) 4. 반환된 요소는 실제로 체크된 이므로 .value를 읽으면 사용자가 선택한 값이 나온다. 1. document.getElementById()를 사용해 버튼과 입력창, 표시할 공간을 선택합니다. 2. 버튼에 **addEventListener()**를 달아 'click' 이벤트가 일어나면 함수를 실행시킵니다. 3. 함수 안에서 입력창의 .value 속성으로 입력된 텍스트를 가져옵니다. 4. 가져온 텍스트를 표시할 공간의 .textContent 속성에 넣어 화면에 보여줍니다.
